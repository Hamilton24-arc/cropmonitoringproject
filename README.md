# GrowfyAI

GrowfyAI is a smart crop monitoring and irrigation web application built with Next.js.  
The system helps farmers monitor crop conditions, analyze plant health, and improve irrigation efficiency using IoT and AI-based insights.

## Features

- Crop monitoring dashboard
- Plant analysis system
- Smart irrigation support
- Farmer dashboard interface
- Real-time data visualization
- Responsive modern UI

## Technologies Used

- Next.js
- React.js
- JavaScript
- CSS
- Node.js

## Installation

Navigate into the project folder: growfyai

Install dependencies:

npm install

Run the development server:

npm run dev

Open: http://localhost:3000 in your browser.
